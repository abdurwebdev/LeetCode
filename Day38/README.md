# Easy JavaScript LeetCode Problems -- README

This README covers **4 beginner-friendly LeetCode problems** solved
using **JavaScript**. These problems help build strong fundamentals in
arrays, indexing, loops, and strings.

------------------------------------------------------------------------

## 1. Concatenation of Array

**LeetCode ID:** 1929\
**Difficulty:** Easy

### Problem Statement

Given an integer array `nums`, return an array `ans` such that:

    ans = nums + nums

### Example

    Input: nums = [1,2,1]
    Output: [1,2,1,1,2,1]

### Key Concepts

-   Array manipulation
-   `push()`
-   Spread operator

------------------------------------------------------------------------

## 2. Build Array from Permutation

**LeetCode ID:** 1920\
**Difficulty:** Easy

### Problem Statement

Given a zero-based permutation `nums`, build an array `ans` where:

    ans[i] = nums[nums[i]]

### Example

    Input: nums = [0,2,1,5,3,4]
    Output: [0,1,2,4,5,3]

### Key Concepts

-   Indexing
-   Array traversal

------------------------------------------------------------------------

## 3. Number of Steps to Reduce a Number to Zero

**LeetCode ID:** 1342\
**Difficulty:** Easy

### Problem Statement

Given an integer `num`, return the number of steps to reduce it to
zero. - If the number is even → divide by 2 - If odd → subtract 1

### Example

    Input: num = 14
    Output: 6

### Key Concepts

-   While loop
-   Modulus operator `%`

------------------------------------------------------------------------

## 4. Defanging an IP Address

**LeetCode ID:** 1108\
**Difficulty:** Easy

### Problem Statement

Given a valid IPv4 address, replace every `.` with `[.]`.

### Example

    Input: address = "1.1.1.1"
    Output: "1[.]1[.]1[.]1"

### Key Concepts

-   Strings
-   `replace()` / `split()`
